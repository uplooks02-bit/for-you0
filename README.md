# 💕 Ladoooo Birthday Surprise

Password-free, interactive birthday website.

## Personalize
Open `script.js` and edit:
```js
const girlfriendName="Ladoooo";
const yourName="Your Name";
```

## Photos
Put these in `images/`:
- photo1.jpg
- photo2.jpg
- photo3.jpg
- photo4.jpg

## Music
Put your MP3 at:
`music/song.mp3`

## Experience
Opening → playful YES/NO → memories → animated envelope → love letter → gifts → quiz → music → final confetti.

## GitHub Pages
Upload the project files to a GitHub repository, then go to Settings → Pages → deploy the `main` branch from `/ (root)`.

No password is included.
